# Функциональный аудит Riffuna

Обновление 2026-10-27: ниже сохранён исходный аудит Qt. Активная реализация перенесена на Kotlin/Compose; актуальная матрица и проверенные границы — в [kotlin-migration.md](kotlin-migration.md).

Проверка 2026-10-26: исходники Riffuna и официальные справки Spotify/Яндекс Музыки. Это сравнение документированных сценариев, а не утверждение о ручном обходе всех экранов чужих приложений. Текущая итерация — локальная 0.2.0.dev4; новый публичный релиз не выпускался.

## Перенесённые сценарии

| Сценарий | Обнаружено в Riffuna | Реализовано в dev4 |
| --- | --- | --- |
| Следующий трек | Только добавление в конец | Явный приоритет «Слушать следующим», включая shuffle и перезапуск |
| Управление очередью | Нет очистки/перестановки/группового удаления | Перетаскивание, Alt+↑/↓, контекстные действия, очистка с сохранением текущей музыки |
| Удаление текущего | Next мог начать список с головы | Продолжение с ближайшей оставшейся записи после удалённой |
| Другие версии + shuffle | Исходный ID мог повторяться в цикле | Текущий элемент очереди остаётся якорем при выборе другого источника |
| Своя библиотека | Только просмотр списков | Локальный поиск по названию/исполнителю, сортировка по имеющимся метаданным |
| Несколько записей | Одиночные действия | Ctrl/Shift/Ctrl+A, групповые операции; порядок/дедупликация сохраняются |
| Плейлист | Только название/состав и шаговая перестановка | Описание, копирование, пакетный перенос, drag-and-drop |
| Воспроизведение лайков/плейлиста | Контекстный запуск отличался от кнопки строки | Единое продолжение внутри отображаемой подборки |
| Навигация | Только кнопки разделов | История разделов/плейлистов назад/вперёд, локальные фильтры восстанавливаются |
| Клавиатура | Поиск, частичная обработка пробела | Переключение треков/режимов, очередь, локальный фильтр, справка; Space работает в списках |
| Маленькое окно | Новые действия не помещались | Прокручиваемая боковая панель, компактные действия и перенос подсказок |

Сортировка и фильтр не переписывают плейлист. Ручная перестановка отключается для отфильтрованного/отсортированного плейлиста: скрытые записи не должны менять место случайно. В likes/history «Сначала новые» использует реальный порядок SQLite, а в плейлистах сортировка по дате не предлагается, потому что дата добавления не хранится.

## Что ещё требует отдельной реализации

| Приоритет | Возможность | Что необходимо |
| --- | --- | --- |
| Высокий | Карточки исполнителей и альбомов | Источник стабильных идентификаторов и метаданных; пока действие «Найти исполнителя» открывает поиск |
| Высокий | Более широкий современный каталог Резонанса | Музыкальные данные и оценка качества рекомендаций; нельзя подменять пробел случайными треками |
| Высокий | Отдельный вид «дальше» с источником подборки | Отделить явные добавления пользователя от контекста плейлиста/рекомендаций; текущая очередь сохраняет весь список |
| Средний | Папки, закрепление, обложки плейлистов | Новая модель организации и управление файлами обложек |
| Средний | Отмена удаления/история правок | Транзакции пользовательских операций и явная команда отмены |
| Средний | Импорт/экспорт коллекций | Версионированный формат, валидация и дедупликация |
| Средний | Системные медиаклавиши и Windows Media Controls | Интеграция Windows с действующим libmpv без второго аудиодвижка |
| Средний | Большие коллекции | Виртуализация строк вместо пересоздания QWidget на каждую запись |
| Позже | Офлайн, синхронизация устройств, Android | Явное управление загрузкой и хранением, серверная модель и клиент |

Это список реальных оставшихся работ, а не скрытые кнопки с заглушками. Тайминги текстов, источники музыки и аудиодвижок в этой итерации не перерабатывались.

## Основания

- Spotify [Play queue](https://support.spotify.com/us/article/play-queue/): очередь, изменение порядка и удаление.
- Spotify [Sort and filter](https://support.spotify.com/us/article/sort-and-filter/): поиск внутри коллекции и сортировка.
- Spotify [Keyboard shortcuts](https://support.spotify.com/us/article/keyboard-shortcuts/): управление с клавиатуры.
- Spotify [Create playlists](https://support.spotify.com/cg-en/article/create-playlists/): редактирование и порядок записей.
- Яндекс Музыка [Плейлисты](https://yandex.ru/support/music/ru/collection/playlists): создание, редактирование и контекстные действия.
- Яндекс [Официальная инструкция веб-приложения](https://inclusion.yandex.ru/tutorials/music-web): «Играть следующим», очередь, плеер и навигация.

Проверка интерфейса выполняется на отдельно помеченных вымышленных QA-данных и временной базе. Эти изображения не являются музыкальным каталогом или пользовательской библиотекой.
