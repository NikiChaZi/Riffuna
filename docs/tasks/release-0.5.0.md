# Riffuna 0.5.0

## Цель

Довести пользовательские возможности Android до Windows 0.4.0, исправить подтверждённые дефекты Windows, измерить и по возможности сократить задержку воспроизведения. Сохранить локальную архитектуру, данные и совместимость подписанного APK. Музыкальные модели «Резонанса» остаются отдельным этапом.

## Приёмка

- Android имеет поиск треков, артистов и релизов, переход из плеера к исполнителю, песни за пределами топ-5, разделы альбомов и синглов, возврат без изменения очереди.
- Android позволяет закрепить трек или плейлист для офлайна, увидеть прогресс, отменить и удалить загрузку, управлять местом и воспроизводить без сети. Неполный файл не считается доступным.
- Android получает недостающие доступные настройки звука, импорт локальных текстов и управление коллекцией по результатам сверки с Windows. Платформенные настройки вывода и обновления адаптируются к Android.
- Windows проверяется через обычные сценарии старта, паузы, seek кликом, следующей записи и сетевой ошибки. Ускорение подтверждается сопоставимыми замерами на новых записях, диагностические отчёты исключают signed URL и пользовательские данные.
- Автономные тесты, lint обеих платформ, проверка пакетов и CI проходят. Проверка обновления выполняется на синтетической библиотеке. Физический Samsung проверяется при наличии ADB, ограничения фиксируются.
- Версия EXE и APK 0.5.0, APK с прежней подписью. Подготовить PR и релиз с SHA-256. Корневой EXE обновляется штатным скриптом после проверки.

## План выполнения

1. Каталог Android и навигация.
2. Закреплённое офлайн-хранилище Android и UI загрузок.
3. Проверка Windows и ускорение старта.
4. Сверка оставшихся различий, интеграция UI, ревью изменений сети и хранения.
5. Сборки, регрессии, обновление и публикация.
