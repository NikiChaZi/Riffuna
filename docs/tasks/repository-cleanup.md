# Уборка репозитория Riffuna

README ведёт на текущий релиз 0.4.0 для Windows и Android. Отчёты и заметки 0.2.x с идентичным содержимым доступны из архивного тега. Основная документация ссылается на этот архив.

Локально перемещаем в соседний архив только явно устаревшие сборки и материалы проверки. Действующий запуск, откат, модели, инструменты сборки и данные пользователя сохраняются. Проверяем ссылки, состав diff и контрольные суммы актуального локального выпуска.
