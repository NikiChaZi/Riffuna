# Навигация по исполнителям в Riffuna для Windows

Сохраняем существующий обзор и добавляем вкладки «Треки», «Альбомы» и «Синглы и EP». Для песен используем расширенную подборку YouTube Music с продолжениями. Если источник ограничивает выборку, сообщаем об этом в интерфейсе. Релизы остаются отдельными сущностями с порядком треков из каталога.

Имя исполнителя в обычном и раскрытом плеере открывает вкладку «Треки». Предпочитаем ссылку на профиль из метаданных конкретной записи. При нескольких исполнителях либо неуверенном совпадении по названию показываем выбор. Навигация по каталогу не вызывает команды воспроизведения.

## Приёмка

- Во время проигрывания «Понарошку» нажатие на имя Доры открывает её треки. Переключение на обзор показывает до пяти популярных песен.
- Если каталог при текущем запросе содержит больше пяти треков, вкладка «Треки» показывает их, включая страницы, которые доступны через «Показать ещё».
- Из вкладки альбомов открывается LOVESONGS, треки идут в порядке источника. Кнопка «Назад» возвращает раздел артиста. Текущий трек, воспроизведение и очередь сохраняются.
- Тест проверяет точный ID, неоднозначные результаты, объединение страниц без дублей и возврат к предыдущему разделу.
