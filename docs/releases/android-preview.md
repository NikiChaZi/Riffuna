# Riffuna для Android

Предварительный выпуск для установки на телефон: Android 8.0 и новее. Скачай **Riffuna-android.apk**, открой файл и разреши установку для приложения, через которое его открыл. Если Riffuna уже установлена, обновление сохраняет библиотеку.

В этом обновлении исправлен сетевой путь воспроизведения: поддерживаются перенаправления аудиосервера и альтернативные форматы, Android предпочитает Opus. HTTPS-запросы выполняются асинхронно; системные Play/Pause учитывают загрузку трека и конец записи. Расширенный прогон проверяет запуск нескольких треков, паузу, перемотку и продолжение воспроизведения.

- Портретный интерфейс: графит, тёплый текст, коралловый акцент, обложки и анимации раскрытого плеера.
- Музыкальный поиск, любимое, история, очередь, перемешивание, повторы и плейлисты.
- Фоновая музыка, системный плеер и управление с гарнитуры, аудиофокус и пауза при отключении наушников.
- Автоматическое восстановление сетевого потока и постоянный кэш. Полностью загруженные записи воспроизводятся без сети; отдельного менеджера загрузок пока нет.
- Синхронизированный текст с подсветкой слов. При наличии только построчных таймкодов расчётная подсветка явно подписана.
- Импорт локальных аудиофайлов через системный выбор документов.

Сервер, аккаунт Riffuna, Python, Node.js и Java на телефоне не требуются. Доступ к YouTube зависит от сети телефона; при необходимости используй свой VPN. Библиотеки Android и Windows пока не синхронизируются; «Резонанс» и расширенный поиск альтернатив остаются в Windows.

Подписанная release-сборка прошла проверки в BlueStacks: полная загрузка потока, перемотка, восстановление ссылки, воспроизведение из кэша без сети, работа после сворачивания и выключения экрана, системная пауза и сохранение библиотеки. Длительная работа и Bluetooth на физическом телефоне ещё требуют проверки. SHA256 приложен отдельным файлом.

Следующие выпуски используют тот же ключ подписи: обновление устанавливается поверх приложения с сохранением библиотеки. Предварительный выпуск не меняет Windows-релиз 0.2.1.
